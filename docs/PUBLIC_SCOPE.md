# Public Research Scope

Included:

- high-level architecture
- sensor roles
- fusion methodology
- validation philosophy
- current evidence boundary

Excluded:

- proprietary product-development details not required for the portfolio
- commercialization/IP planning
- detailed BOM and supplier strategy
- private datasets
- private calibration data
- unreleased prototype-specific implementation details

The repository is intended to demonstrate engineering reasoning without exposing the entire private R&D project.
