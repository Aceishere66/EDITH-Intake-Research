# Current Stage and Evidence Boundary

EDITH Intake is currently a research/prototyping project.

## Established

- system architecture
- proposed sensor roles
- event-triggered power concept
- hardware/software boundaries
- sensor-fusion strategy
- candidate model/data stack
- validation methodology
- staged prototype planning

## Not yet established as measured EDITH results

- event-detection recall
- drinking-detection recall
- portion/consumption error
- daily calorie error
- all-day battery behavior
- final wearable form-factor suitability

Any numerical targets discussed in the private planning repository are targets, not achieved measurements.

## Why this distinction matters

The project is intentionally presented as an engineering research problem. A portfolio should make the reasoning, architecture and planned validation inspectable without converting hypotheses into product claims.
